## Hired web — 2018–2024

Work Constantine did as a web engineer / team lead. React, Next.js, TypeScript. Production systems with real money and real uptime. This is the job. Games are not listed here.

**2018 — Stripe payments.** One-day job: token → customer → charge. Hard part was deploying on the client's machine over a shared screen.

**2018 — Dental clinic admin.** CRM for clients, doctors, appointments, and a teeth-shaped checkbox grid so a doctor could mark which tooth had work. React, MobX, TypeScript, Ant Design, GraphQL.

**2019 — Hotel staff UI.** Figma to React + SASS. Reservations, rooms, guests.

**2019 — Analytics widget kit.** NPM package of reusable charts. Bug fixes, new chart types, bundle-size cuts, Redux cleanup. React, BizCharts, Ant Design.

**2020 — IVF report API.** JSON in, PDF out: charts, tables, images, unit tests, validation. Frontend waited up to 60s then downloaded. React-pdf, Node, Express, serverless.

**2020 — Car rental service.** UI/UX, maps, tables, charts, offer cart, unit tests. React, TypeScript, Redux, Tailwind, Leaflet, Jest.

**2021 — Factory CRM.** Giant project, 10+ microservices. Bugs across service boundaries, docs, internal libraries, broken PWA, outdated packages, performance. React 17, Redux, Recoil, Material UI 4.

**2021 — Atlassian gadgets.** Productivity / task-time analytics widgets. More filters, fewer clicks, better errors. Atlaskit, React 16, Redux, VictoryCharts, TypeScript.

**2022 — Task manager with rewards.** From scratch: auth, orgs, teams, invites, CI/CD. Each ticket could pay money, time off, or a gift. React 18, TypeScript, Stripe, Plaid, Vercel.

**2022 — Restaurant point of sale.** Tablet orders, payments, customer lookup, custom orders. React, TypeScript, Material UI, Redux.

**2024 — Insurance arbitration.** Led the frontend team. Auth, orgs, users, signed offers and responses, CI/CD, eslint + husky. Next.js, TypeScript, Tailwind, shadcn, NextAuth, Zustand.

**2020 — Bachelor, Software Engineering.** C++ terminal games, then FiveM RP, then React. University was a push; most of the useful work was self-taught.
